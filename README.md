# Business-Analyst-EliteIntern
This repository contains four tasks assigned by EliteIntern, namely: Market Basket Analysis, Estimating Retail Prices, Analyzing Customer Feedback, and Predicting Avocado Prices.
📊 Business Analytics Internship Project – ELiteTech
This repository contains a collection of real-world data analysis tasks completed during my internship at ELiteTech. The goal was to apply business analytics and data science techniques to solve practical business problems using Python and publicly available datasets.

🔧 Tools & Libraries
Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Mlxtend

Jupyter Notebooks

Data Visualization & EDA

Regression, Forecasting, Sentiment Analysis, Market Basket Analysis

✅ Tasks Completed
🛒 1. Market Basket Analysis
Identified frequently purchased product combinations using the Apriori algorithm.

Discovered associations between items to guide product placement, bundle offers, and promotions.

Tools: mlxtend, pandas

📦 2. Estimating Retail Prices (Flipkart Dataset)
Analyzed wireless earbuds pricing across Flipkart to benchmark our product price.

Visualized competitor pricing distribution.

Concluded that our proposed price (₹1170) is highly competitive vs. the market average (₹22,630).

Tools: pandas, matplotlib

💬 3. Customer Feedback Analysis
Performed sentiment analysis using CSAT (81.7%) and NPS (63.4) metrics.

Identified areas for improvement and strengths from feedback data.

Suggested loyalty program ideas based on promoter score.

Tools: pandas, seaborn, matplotlib

🥑 4. Avocado Price Forecasting
Analyzed historical pricing trends of avocados in the U.S.

Used linear regression to forecast prices for the next 6 months.

Provided actionable insights for inventory planning and supply chain strategy.

Tools: sklearn, seaborn, matplotlib
